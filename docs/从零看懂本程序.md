# 从零看懂本程序（给 Codesys / 电气工程师）

Python 里没有 PLC 的“功能块语言”，但我们**故意写成和你 Codesys 一样的骨架**。  
先建立对应关系，再按文件读，就不会迷路。

---

## 1. 一句话：程序在干什么？

工控机上的 Python 程序，每 **50ms** 扫一遍（像 PLC 的 OB1 / Main 任务）：

1. 读按钮、急停、光电、压鞋机信号  
2. 跑初始化 / Station1～6（互相并行）  
3. 刷新 HMI 上的记忆、灯、状态  

有真机时：控两台法奥臂、四路相机、夹爪、压鞋机。  
现在默认 **Mock**：没有硬件也能点界面看流程。

## 2. Codesys ↔ Python 对照表（必看）

| 你熟悉的 Codesys | 本项目里在哪 |
|------------------|--------------|
| `GVL_Memory.Memory_BOOL[1]` | `ctx.gvl.Memory_BOOL[1]` |
| `GVL_Station.Station[2].Auto_A[10]` | `ctx.gvl.Station[2].Auto_A[10]` |
| `Busy` | `ctx.gvl.Station[2].Busy` |
| `Main.Running / Paused / Stop` | `ctx.gvl.Main.Running / Paused / Stop` |
| `IF 条件 THEN Auto_A[10]:=10` | 各 `stations/stationX_*.py` 前半段 |
| `CASE Auto_A[10] OF 10: 20:` | `match A[10]:` / `case 10:` / `case 20:` |
| `Ton` 延时 | `delay_start` + `delay_done`（更简单） |
| 周期任务 OB1 | `core/coordinator.py` 里的 `cycle()` |
| 硬件 IO / 轴 | `devices/` 目录（机器人、夹爪、压鞋机） |
| 可视化 / HMI | `hmi/` 目录（PySide6 窗口） |

**Python 里 `:=` 写成 `=`，`AND` 写成 `and`，`NOT` 写成 `not`，`TRUE/FALSE` 写成 `True/False`。**

## 4. 一个 Station 固定四段（背下来）

每个 `stations/stationX_*.py` 的 `cycle(ctx)` 都是这四段，和你 Codesys 一样：

```text
① Busy
   IF 所有 Auto_A=0 THEN Busy:=FALSE ELSE Busy:=TRUE

② 停机清零
   IF Stop OR EStop OR Alarm THEN 所有 Auto_A:=0

③ 进入条件
   IF 互锁条件 AND NOT Busy AND Running AND NOT Paused THEN
       Auto_A[10]:=10

④ CASE（暂停时不跑）
   IF NOT Paused THEN
       CASE Auto_A[10] OF
         10: ... ; Auto_A[10]:=20;
         20: ... ; Auto_A[10]:=0;
       END_CASE
```

## 5. 建议学习顺序（按天）

**第 1 步（10 分钟）**  
打开 `stations/station2_robot1.py`，只看注释里的 `(* Codesys *)`，对照你以前的 ST。

**第 2 步**  
打开 `core/gvl.py`，看 `Memory_BOOL`、`Station[2].Auto_A`、`Main`。

**第 3 步**  
打开 `core/plc_util.py`，弄懂：
- `delay_start` / `delay_done` = 简易 Ton  
- `pulse_cmd` = “这一步只发一次运动指令”（防止每 50ms 重复 Move）

**第 4 步**  
打开 `core/coordinator.py`，看 `cycle()`：就像 OB1 依次调用各 Station。

**第 5 步**  
运行 `python3 main.py`：初始化 → 启动 → 点「模拟光电感应到位」，看 Station 状态和记忆变化。

**第 6 步（以后）**  
再碰 `devices/`（真机通信）、`vision/`（相机）、`hmi/`（界面）。

## 7. 改流程时你改哪里？

- **改步序 / 互锁**：只改 `stations/stationX_*.py`  
- **改 IP / 点位**：只改 `config/default.yaml`  
- **改界面按钮**：改 `hmi/pages/`  
- **一般不要先改** `devices/`、`vision/`（等流程跑通再接真机）

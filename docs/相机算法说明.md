# 相机算法说明（接口 · 调用处 · 实现细节）

> 本文说明**生产主流程与 HMI**里所有用到相机的视觉能力：  
> **接口是什么** → **谁在哪里调用** → **内部具体做什么** → **入参/出参/配置**。  
>
> 总调用链与双槽对账见 [视觉对账_双槽.md](视觉对账_双槽.md)。  
> 四路相机：皮带 cam1、眼在手上 cam2、放料开口 cam3、取料开口 cam4。槽会转到开口下，顶视相机不跟槽转。

**Station6（压合/旋转）不用相机。**

---

## 0. 对象从哪里来

| 符号 | 类型 | 如何拿到 |
|------|------|----------|
| `ctx` | `AppContext` | 协调器 / 工位 `cycle(ctx)` |
| `ctx.vision` | `VisionService` | `AppContext` 启动时注入四路 `cameras` + `vision` 配置 |
| `ctx.cameras` | `dict[str, OrbbecCamera]` | `cam1`…`cam4` |
| `algo` | `AlgorithmModule` 单例 | `from algorithm_module import algo` |
| `vis_cfg` / `self.cfg` | `dict` | 通常是 `ctx.cfg["vision"]`（整段 vision 配置） |

|------|------|--------------|-----------|

## 2. 结果类型（接口返回值）

### 2.1 `vision.vision_service.BeltPickResult`（工位实际用的）

与 `algorithm_module.results.BeltPickResult` 字段对齐；Service 层多一个 `snap_id`。

| 字段 | 类型 | 含义 |
|------|------|------|
| `ok` | `bool` | 是否检出有效取料位 |
| `x,y,z` | `float` | 机器人**基座**坐标 mm |
| `rx,ry,rz` | `float` | 姿态 °（真机 rx/ry 多用默认；rz=yaw） |
| `is_left_shoe` | `bool` | 左鞋 / 右鞋 |
| `message` | `str` | 人可读说明 |
| `source` | `str` | `"legacy_yolo_handeye"` / `"shield_mock"` 等 |
| `toe_offset_in_grasp_tcp` | `list[float] \| None` | 抓取 TCP 下鞋头偏移 `[dx,dy,dz]` mm |
| `shoe_length_mm` | `float` | 抓取中心→鞋头距离 mm |
| `snap_id` | `str` | 落盘快照 id（`logs/vision_snaps/`） |
| `vis_bgr` | `ndarray \| None` | 叠图（algo 层有；Service 常另 publish） |

### 2.2 `SlotPhotoResult`（`vision_service.py`）

| 字段 | 类型 | 含义 |
|------|------|------|
| `ok` | `bool` | 拍照/分类是否成功 |
| `has_material` | `bool` | 槽内有鞋 |
| `is_left_slot` | `bool \| None` | 当前放料口是否左鞋槽（由槽号 1/3 左、2/4 右推导） |
| `slot_id` | `int` | 当前开口下 PLC 槽号 1–4；未知为 0 |
| `message` | `str` | 说明 |
| `snap_id` | `str` | 快照 id |

### 2.3 `algorithm_module.results`（algo 层）

| 类型 | 主要字段 |
|------|----------|
| `SlotResult` | `ok, has_material, slot_id, message, confidence, num_boxes, vis_bgr` |
| `ToeAlignResult` | `ok, aligned, label, x_label, y_label, source, message, vis_bgr` |
| `RodOffsetResult` | `ok, dx, dy, dz, slot_id, message, vis_bgr`（基座 mm） |

### 2.4 `vision.guide.GuideResult`

| 字段 | 含义 |
|------|------|
| `ok, aligned, dx, dy, drz, message` | HMI「贴边引导」用；生产对位主路径用 `ToeAlignResult` + MoveL |

## 3. 业务层接口 `VisionService`（工位首选）

文件：`vision/vision_service.py`  
实例：`ctx.vision`

### 3.1 `photo_belt_pick` — 皮带取料位

```python
def photo_belt_pick(
    self,
    default_z: float,
    default_rx: float,
    default_ry: float,
    *,
    persist: bool = True,
) -> BeltPickResult
```

| 项 | 内容 |
|----|------|
| **做什么** | cam1：Mock 用 yaml 示教鞋位；真机 grab + `algo.detect_belt_pick` → 基座取料位姿 |
| **用在哪里** | **Station1** `stations/station1_belt_photo.py` 步 5 等待后步 10；HMI `vision_workspace._test_belt` / `zero_to_pick_page` |
| **入参** | `default_z/rx/ry`：无测到 Z/姿态时的默认（工位常传当前 `PickPose`）；`persist`：是否写视觉快照 |
| **出参** | `BeltPickResult`（含 `snap_id`） |
| **副作用** | `publish_vis("cam1", …)`；可选 `_persist_shot`；Mock 时更新 `_belt_mock_*` 调试态 |
| **下游** | Station1 步 20 写入 `gvl.PickPose` + `gvl.BeltPickSnapshot`；Mock 成功后 `commit_belt_mock_advance()` |

**Station1 调用摘录：**

```python
r = ctx.vision.photo_belt_pick(
    default_z=float(gvl.PickPose.get("z", 120)),
    default_rx=float(gvl.PickPose.get("rx", 180)),
    default_ry=float(gvl.PickPose.get("ry", 0)),
)
```

失败会按 `vision.photo_retry` / `photo_retry_interval_s` 重试，超限报 `VISION1`。

自动流程：原始光电 → `gvl.BeltPresent`（`belt_filter_ms`）→ 步 5 等 `belt_photo_delay_ms`（默认 500）→ 步 10 才 `photo_belt_pick`。

### 3.3 `photo_place_slot` — 放料槽

```python
def photo_place_slot(self, *, persist: bool = True) -> SlotPhotoResult
```

| 项 | 内容 |
|----|------|
| **做什么** | cam3：Mock 看 `mock_place_has_material` / `mock_place_is_left`；真机 `algo.classify_slot_occupied`（检测） |
| **用在哪里** | **Station3** 步 10；HMI「测放料槽」 |
| **真机要点** | 只信「有无料」；`slot_id` 来自入参/`set_opening_slots`/`vision.opening`；`is_left_slot` **仍默认 True** 以免 Station 改接口 |
| **Station3 步 20** | 空槽且左右对应 → Mem3=0,Mem4=1,Mem10=0 可放；否则可能 Mem10=1 只转不压 |

```python
r = ctx.vision.photo_place_slot()
```

### 3.4 `photo_pick_slot` — 取料槽 + 压杆

```python
def photo_pick_slot(self, *, persist: bool = True) -> SlotPhotoResult
```

| 项 | 内容 |
|----|------|
| **做什么** | cam4：Mock 只判有料；真机先槽**检测**，**有料再** `algo.measure_rod_offset_mm(..., slot_id=)` |
| **用在哪里** | **Station4** 步 10；HMI「测取料槽」 |
| **副作用** | 成功且压杆 ok → `self.last_pick_xy_offset_mm = [dx,dy,dz]`；失败清空偏移 |
| **Station4 步 20** | `Mem7=1`，`Mem6=has_material` |
| **Station5** | `_slot_pick_pose` 把偏移加到示教 `slot_pick` 的 x/y |

```python
# station4
r = ctx.vision.photo_pick_slot()

# station5
pose = numeric_pose(ctx.pose("robot2", "slot_pick"))
off = ctx.vision.last_pick_xy_offset_mm
pose["x"] += off[0]; pose["y"] += off[1]  # 有偏移时
```

## 4. 算法门面 `algo`（`algorithm_module`）

文件：`algorithm_module/algorithm_module.py`  
单例：`from algorithm_module import algo`

### 4.1 生产接口一览

| 方法签名 | 具体做什么 | 落到哪 | 谁调用 |
|----------|------------|--------|--------|
| `detect_belt_pick(cameras, vis_cfg, default_z, default_rx, default_ry) -> BeltPickResult` | cam1 真机 YOLO+手眼取料 | `production` → `legacy_pipeline.detect_belt_legacy` | **仅** `VisionService.photo_belt_pick` 真机分支 |
| `detect_belt_shoes_mock(vis_cfg) -> list` | 读 yaml 示教鞋列表 | `template_match.detect_belt_shoes_mock` | `photo_belt_pick` Mock；`commit_belt_mock_advance` |
| `classify_slot_occupied(image_bgr, vis_cfg=None) -> SlotResult` | 槽空/有鞋（默认检测） | `legacy_pipeline.classify_slot_occupied` → `slot_check_dect` | `photo_place_slot` / `photo_pick_slot` / `test_slot_classify` |
| `classify_toe_align(image_bgr, vis_cfg=None) -> ToeAlignResult` | 鞋头 ImgAct 双头，缺权重退回 classify | `legacy_pipeline.classify_toe_align` | `toe_place_assist`；`guide_place_edge`；`test_toe_align_label` |
| `measure_rod_offset_mm(cameras, vis_cfg=None, image_bgr=None, slot_id=0) -> RodOffsetResult` | 压杆相对 gripper preset → 基座 mm | `legacy_pipeline.measure_rod_offset_mm` → `position_obb` 等 | `photo_pick_slot` 有料时；监控可传图 |
| `measure_rod_offset_tuple(...)` | 同上，元组兼容旧调用 | 包装上一函数 | `test_rod_offset` |

另有投产/训练接口（`write_intrinsics_*`、`record_handeye_sample`、`solve_handeye_and_write`、`capture_to_slot`、`train_cmd` 等），见 §7。

## 5. 底层实现 `legacy_pipeline`（具体算法）

文件：`vision/legacy_pipeline.py`

### 5.1 `detect_belt_legacy(cameras, vis_cfg, default_z, default_rx, default_ry)`

| 项 | 内容 |
|----|------|
| **返回** | `(result_dict, vis_bgr)` |
| **具体步骤** | 1) `get_shoe_vision` 加载/复用 `ShoeVision`（读 `shoe_vision_config.json`，FrameAdapter 接 cam1）<br>2) `get_shoe_base_pose_toe_and_arc_points(vision=sv, side="all")`：鞋 OBB、左右脚、楦、深度、手眼<br>3) 同时两只时取**操作工视角左侧**（基座 X 最小）；`is_left_shoe` 仍是该鞋的左右脚类别<br>4) 用该鞋楦心与鞋头点算 `shoe_length_mm` / `toe_offset_in_grasp_tcp`<br>5) 若无鞋头分割模块则退回 `sv.get_all_shoe_points()`，同样按 X 最小选，鞋长默认 120 |
| **失败** | `ok=False` + message（未就绪 / 未检出 / 无楦心） |

`result_dict` 键：`ok,x,y,z,rx,ry,rz,is_left_shoe,message,source,toe_offset_in_grasp_tcp,shoe_length_mm`。

---

### 5.2 `classify_slot_occupied(image_bgr, vis_cfg) -> (occupied|None, msg, conf, extra)`

| 项 | 内容 |
|----|------|
| **具体** | 默认 `slot_check_dect.SlotChecker` 检测；`mode=classify` 或检测权重缺失时走 `slot_check.py` |
| **类别** | 有框 → 有鞋 `True`；无框 → 空槽 `False` |
| **配置** | `vis_cfg["slot_check"]["mode"|"model_path"|"classify_model_path"|"imgsz"|"conf"]` |

对账表：[视觉对账_双槽.md](视觉对账_双槽.md)

---

### 5.3 `classify_toe_align(image_bgr, vis_cfg) -> (label, msg)`

| 项 | 内容 |
|----|------|
| **具体** | 优先 `vision/toe_imgact.py`：ImgAct 双头 X（0停/1前/2后）Y（0停/1左/2右）；缺权重退 `ultralytics.YOLO` classify |
| **到位判定**（在 `production.classify_toe_align`） | ImgAct：`x_label==0` 且 `y_label==0`；旧分类：`label.lower()` ∈ `0/aligned/ok/到位/贴紧/stop/done` |
| **配置** | `vision.toe_align.backend/model_path/later_model_path/classify_model_path/imgsz` |

---

### 5.4 `measure_rod_offset_mm(cameras, vis_cfg, image_bgr=None) -> (ok,dx,dy,dz,vis,msg)`

| 项 | 内容 |
|----|------|
| **相机** | `vision.position.camera`（默认 **cam4**）；`camera_id` 1=左配置 / 2=右配置（选 K、ROI、preset） |
| **具体步骤** | 1) grab 或用传入图；无深度用 `fallback_z_mm` 平面<br>2) 读 `position_config.yaml`<br>3) `OBBOnlyDetector(rod模型)` + `detect_with_roi_filter`<br>4) 取 class0 检测的相机 X，减 `gripper_preset_xyz[0]` 得 `distance`<br>5) `build_robot_xyz_offset(camera_id, distance, cov, cov)` → **基座 mm** |
| **Station5 用法** | 只用返回的 **dx, dy** 加到示教点（dz 一般不叠加到 slot_pick） |

## 6. 工位侧「非 VisionService」接口

### 6.1 `stations.toe_place_assist.run_toe_align_step`

```python
def run_toe_align_step(ctx, *, side_left: bool) -> Dict[str, Any]
```

| 项 | 内容 |
|----|------|
| **用在哪里** | **Station2** 放料步（`station2_robot1.py` Auto_A[20] 约步 40） |
| **具体** | 真机：cam2 `grab` → `algo.classify_toe_align`；到位则 `{done:True}`；否则按 label/`toe_align_advance_mm` 对 robot1 `move_l` 相对推进，返回 `{done:False}` 供循环再拍<br>Mock/异常：`_run_simple_toe_align`（默认直接 `done=True` 不运动） |
| **返回键** | `done, ok, message` |

与 HMI `guide_place_edge` **同源分类算法**，但工位自己取图并驱动运动。

## 8. 配置与模型（接口读哪些键）

### 8.2 典型模型路径

| 用途 | 路径示例 |
|------|----------|
| 皮带鞋/左右/楦 | `shoe_vision_config.json`；`casbot_yolo_obb360` + `casbot_yolo_point4d`（`bash init.sh` clone，不进 git） |

| 压杆 | 与双槽相同：躲开 obb360 别名后的普通 OBB `obb.pt` |

## 9. 端到端调用图（生产）

```
光电到位
  → Station1.photo_belt_pick
       ├─ Mock: algo.detect_belt_shoes_mock
       └─ Real: algo.detect_belt_pick → detect_belt_legacy → ShoeVision + 鞋头测长
  → PickPose / BeltPickSnapshot

Station2 取皮带（无相机）→ 放槽
  → run_toe_align_step
       └─ algo.classify_toe_align → ImgAct 双头（缺权重退 YOLO classify）；运动仍在 toe_place_assist

Station3.photo_place_slot
  └─ algo.classify_slot_occupied → SlotChecker → Mem3/4/10

Station6 压/转（无相机）

Station4.photo_pick_slot
  ├─ classify_slot_occupied
  └─ 有料: measure_rod_offset_mm → last_pick_xy_offset_mm → Mem6/7

Station5 槽取料 = slot_pick + last_pick_xy_offset_mm（不再拍照）
```

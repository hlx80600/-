# 四槽视觉 vs 双槽产线对账

对照仓库：双槽 `Casbot_Press_Shoes`（`shoe_vision_seg.py` 等）。  
四槽只改视觉门面，**不改** `stations/` / `main.py` / `devices/` / `core/`。

现场相机 **4 路**（不是每槽一台顶视）：

| 相机 | 角色 | 装在哪 |
|------|------|--------|
| cam1 | 皮带上料 | 固定 |
| cam2 | 鞋头对位 | 上料臂眼在手上 |
| cam3 | 放料开口（上料槽） | 开口上方，槽转相机不转 |
| cam4 | 取料开口（下料槽） | 开口上方，槽转相机不转 |

PLC `place_slot` / `pick_slot`（1–4）表示**当前开口下是几号槽**。

---

## 接口差异

| 能力 | 双槽产线 | 四槽改前 | 四槽改后（视觉侧） |
|------|----------|----------|-------------------|
| 皮带抓取 | `ShoeVision`：鞋 OBB + 左右脚 + 楦 + 深度 + 手眼 | `detect_belt_legacy` 已接同一套 | 保持；字段仍是 `(x,y,z,yaw,is_left_shoe)` |
| 槽占用 | **检测** `slot_check_dect`（有框=有鞋）`7.13_dect_1.pt` | **分类** `slot_check.py`（0空/1有）`7.10slot_check.pt` | 默认走检测；分类仅作缺权重兜底 |
| 压杆/取鞋偏移 | `position.py`：鞋 X − 示教 preset X | `measure_rod_offset_mm`：`camera_id` 1/2 = 左/右槽相机 | 公式不变；按开口 cam3/cam4 + 可选 `slot_id` 取 preset |
| 鞋头对位 | ImgAct 双头 `0907best` + `_later`：X 停/前/后，Y 停/左/右 | YOLO 二分类 `0722best.pt` | 优先 ImgAct 推理；运动仍归 Station，本仓库不改 `toe_place_assist` |
| 槽语义 | 左/右两台槽相机 | `is_left_slot`，真机 cam3 写死 True | 结果增加 `slot_id`；`is_left_slot` 保留给现有 Station |
| 手眼 | 单基座一张矩阵 | 配置里仍是皮带一份 | 装机后：cam1/cam2/cam3→robot1，cam4→robot2 |

## 控制同事继续用的接口（签名兼容）

Station 仍调用：

- `ctx.vision.photo_belt_pick(...)`
- `ctx.vision.photo_place_slot()` / `photo_pick_slot()`
- `algo.classify_toe_align(...)`（Station2 自己取图）
- `ctx.vision.last_pick_xy_offset_mm`

新增字段是附加的：`SlotPhotoResult.slot_id`、`ToeAlignResult.x_label` / `y_label`。旧字段含义不变。

`slot_id` 来源（不改 Station）：`photo_*(slot_id=)` → `VisionService.set_opening_slots` → `vision.opening`。未设置时为 `0`。不要用 `press.mock_*_slot` 冒充当前槽号。

## 0. 改参数的总原则

| 原则 | 说明 |
|------|------|
| **唯一参数总表** | 几乎所有现场可改项都在 **`config/default.yaml`** |
| **不要改驱动源码改 IP** | 不要去改 `devices/robot_fr5.py`、夹爪驱动里写死的地址 |
| **HMI 可改并写回** | 「通信配置」「压机信号」「示教点位」「运动参数」「负载工具」等点**保存**后写回同一 yaml |
| **改完多数要重启** | IP、CAN、相机 serial、Mock 开关、扫描周期等：保存后**重启 `python3 main.py`** 最稳妥 |
| **示教点即时生效** | 「示教点位」保存后一般立即进内存；仍建议核对 yaml 已写入 |

下面按设备列出：**改什么 → yaml 路径 → HMI 在哪改 → 含义**。  
表中「当前示例」以仓库里 `default.yaml` 为准，现场以你机台上实际保存值为准。

### 1.5 压鞋机 — 每槽点位地址（槽 1～4）

路径统一为：

```text
press.slots.<槽号>.addr_xxx
```

| yaml 字段 | 含义（界面中文） | 在哪改 |
|-----------|------------------|--------|
| `addr_shoe_placed` | 放鞋完成 | **压机信号** → 选槽 → 地址表 |
| `addr_motor_start` | 压杆电机启动 | 同上 |
| `addr_motor_done` | 压杆电机完成 | 同上 |
| `addr_move_distance` | 压杆距离 | 同上 |
| `addr_slot_up` | 槽上升/压合 | 同上 |
| `addr_rod_aligned` | 压杆回正 | 同上 |
| `addr_rod_in_pos` | 压杆到位 | 同上 |
| `addr_base_down` | 大座下到位 | 同上 |
| `addr_rod_home` | 压杆原点 | 同上 |
| `addr_work_status` | 工作状态 | 同上 |
| `addr_estop` | 急停相关 | 同上 |
| `addr_rod_forward` / `back` / `go_home` | 压杆进/退/回原 | 同上 |
| `addr_press_up` / `addr_press_down` | 大座升/降 | 同上 |
| `default_move_distance_mm` | 默认压杆行程 mm | 同上 / yaml |
| `auto_motor_on_press` | 压合时自动开电机 | yaml |

槽 1、2 在仓库 yaml 里已填现场号；槽 3、4 若为 `0` 表示尚未按现场表配置，投产前必须按接线表补全并保存。

## 2. 分设备 Mock（只有部分真机时）

不要只改 `system.use_mock`。应改各设备自己的开关，例如：

```yaml
robots:
  robot1:
    use_mock: false   # 上料真机
  robot2:
    use_mock: true    # 下料仍模拟
grippers:
  gripper1: { use_mock: true }
  gripper2: { use_mock: true }
press:
  use_mock: true
vision:
  use_mock: true
cameras:
  cam1: { use_mock: true }
  cam2: { use_mock: false }   # 例：只开对位相机
```

HMI「通信配置」页有对应勾选。改完**重启程序**。

## 3. 安装与启动

```bash
cd 莆田鞋厂四槽机器控制程序
python3 -m pip install --user --break-system-packages -r requirements.txt
python3 main.py
```

- 默认多数设备可 Mock，**无真机也能打开 HMI**。  
- 接真机：对应 `use_mock: false`，并安装法奥 SDK（常见：`pip install -e ../fairino`，以你机器上的 SDK 路径为准）。  
- 窗口闪退：Wayland 用 `QT_QPA_PLATFORM=wayland python3 main.py`；X11 需 `sudo apt install libxcb-cursor0`。

## 4. HMI 分页与操作顺序

**完整逐步说明（含手眼标定点击顺序、检查清单）：** [界面操作手册.md](界面操作手册.md)。

### 4.0 新机投产总顺序

1. **通信配置**（IP/CAN/相机/Mock）→ 保存 → **重启**  
2. **负载工具** → **示教点位** → **运动参数** → **压机信号**  
3. **视觉采图**（挂/训模型）  
4. **视觉**：ROI → 内参 → 手眼 → 检测测试 → 采图训练挂/训模型；**报警记录 → 运行快照** 确认能翻到图  
5. **屏蔽取料**（仅 cam1 模拟时）→ **夹爪调试**  
6. **空跑 / 工位调试** → **运行监控** 自动启动

### 灯语

- 绿常亮 = 自动运行  
- 黄+绿常亮 = 初始化完成（READY，可启动）  
- 黄常亮 = 停止后 / 未初始化  
- 黄闪 = 初始化中 / 暂停 / 单步中  
- 红常亮 = 报警  
- 红闪 = 急停

## 5. Mock 下快速走通自动流程

1. 模式选 **自动**。  
2. **初始化** → READY（黄+绿）。  
3. 「空跑联调」启用；或运行监控勾光电、Mock 取料槽有料、放料空槽。  
4. 「屏蔽取料」确认左右鞋示教点（cam1 Mock 时必做）。  
5. **启动**。观察 Station1→2→3→…→6（先压合再旋转）。  

主流程文字说明见 [程序总览.md](程序总览.md)。

---

## 6. 单步调试

1. 模式 **单步** → **初始化** → **启动**。  
2. 「工位调试」选 Station / Auto → **武装所选 Auto**（互锁不够可勾 **调试旁路**，需 `system.allow_debug_bypass: true`）。  
3. **执行当前步** / **下一步**。  
4. **中止本 Auto** 清空该站步号（记忆需在监控页改）。  

鞋头引导失败（cam2）：常停在放料点、夹爪仍夹着 → 暂停 → 报警复位 → 启动 → 从引导步继续。

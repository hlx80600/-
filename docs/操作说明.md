# 莆田鞋厂四槽机器控制程序 — 操作说明

面向：电气工程师转机器人，Python 基础较弱。  
目标：从安装 → 标定 → 单步验证 → 自动投产。

---

## 0. ★ 改机器人地址（最常问）

**文件：** `config/default.yaml`（不要去改 `devices/robot_fr5.py`）

| 设备 | yaml 位置 | 默认值 |
|------|-----------|--------|
| 上料机器人 | `robots.robot1.ip` | `192.168.1.105` |
| 下料机器人 | `robots.robot2.ip` | `192.168.1.115` |
| 压鞋机 | `press.ip` / `press.port` | `192.168.1.50:502` |
| 夹爪 | `grippers.gripper1/2.can_id` | `0x103` / `0x104` |

也可打开 HMI → **通信配置** → 改 IP → **保存配置**（写回同一 yaml）。  

### 分设备 Mock（只有一台真机时）

不要只改 `system.use_mock`。应改各设备自己的开关，例如：

```yaml
robots:
  robot1:
    use_mock: false   # 上料真机
  robot2:
    use_mock: true    # 下料仍模拟
grippers:
  gripper1: { use_mock: true }
  gripper2: { use_mock: true }
press:
  use_mock: true
vision:
  use_mock: true
```

HMI「通信配置」页也有对应勾选。改完**重启程序**。

## 1. 安装与启动

```bash
cd 莆田鞋厂四槽机器控制程序
python3 -m pip install --user --break-system-packages -r requirements.txt
python3 main.py
```

- 默认各设备 `use_mock: true`，**无真机也能打开 HMI**。  
  接真机时只把对应设备的 `use_mock` 改为 `false`（见上文「分设备 Mock」），并安装法奥 SDK（`pip install -e ../fairino`）。
- 若窗口闪一下就退出：本机为 Wayland 时请用终端运行，或在 Cursor 里选调试配置 **「运行主程序」**（已写好 `QT_QPA_PLATFORM=wayland`）。  
  也可用：`QT_QPA_PLATFORM=wayland python3 main.py`  
  X11 用户需：`sudo apt install libxcb-cursor0`

## 2. HMI 分页

| 页 | 用途 |
|----|------|
| 运行监控 | 初始化/启动/暂停/停止/急停、三色灯、记忆、Mock 信号 |
| 产量统计 | 下料记件、CT、UPH |
| 工位调试 | 按工位/Auto 单步跑、调试旁路 |
| 运动参数 | 按程序步调 vel / 平滑 |
| 视觉采图 | 新机：模型/训练/写 json 手眼/测皮带/试抓 |
| 视觉调试 | YOLO 出图/ROI/内参/检测测试 |
| 示教点位 | 上料 R1 / 下料 R2 示教点、过渡点 |
| 屏蔽取料 | cam1 Mock 皮带取料示教 |
| 空跑联调 | 无真机走通工位 1～6 |
| 负载工具 | 两臂负载与 TCP |
| 压机信号 | 左右口、槽号、Modbus |
| 通信配置 | 机器人 IP、压鞋机、夹爪 CAN、光电 DI |
| 报警记录 | 历史与复位 |
| 使用说明 | 各页操作释义（长说明只在这一页） |

**相机监控**是独立窗口（不在标签栏）：启动后自动弹出，可与调试页同时显示。关掉后点主界面顶部「相机监控窗口」再打开。

### 灯语

- 绿常亮 = 自动运行  
- 黄+绿常亮 = 初始化完成（READY，可启动）  
- 黄常亮 = 停止后 / 未初始化  
- 黄闪 = 初始化中 / 暂停 / 单步中  
- 红常亮 = 报警  
- 红闪 = 急停  

### 记忆

- `GVL_Memery[1..10]` 仅程序内部 BOOL。  
- **自动运行中锁定**；暂停/停止/报警/单步/空闲时可勾选修改。

## 3. Mock 下快速走通自动流程（推荐先做）

1. 打开软件，模式选 **自动**。  
2. 点 **初始化**（Mock 会很快完成）→ 状态变 READY（黄+绿）。  
3. 在 Mock 区勾选：  
   - 上料皮带光电 DI  
   - Mock取料槽有料（若测下料）  
   - Mock放料槽方向=左脚，且不要勾「放料槽有料」（空槽）  
4. 点 **启动**。  
5. 观察 Station1 拍照 → Station2 取料 →（需要 Mem[4]）Station3 会因旋转到位自动拍放料槽 → Station2 放料 → …  
6. Station6 旋转时 Mock 会约 1.2s 后自动「旋转完成」；也可手动点「模拟压鞋机旋转完成」。

## 4. 单步调试（验证每个动作）

1. 模式切 **单步** → **初始化**（单步页可点「单步初始化-执行/下一步」逐步点）→ **启动**。  
2. 选 Station / Auto → **武装所选 Auto**。  
   - 若互锁不满足：勾选 **调试旁路**。  
3. 点 **执行当前步**：该步自动运行直到条件满足（运动到位/延时到），然后停住。  
4. 再点 **下一步**：进入并执行下一步，再次等到完成停住。  
5. **中止本 Auto** 可清空该站步号（记忆不自动清，可在监控页改）。

引导失败（相机2）：停在放料点、夹爪仍夹着；报警后按暂停处理 → **报警复位** → 启动 → 从引导步继续。

## 5. 视觉：四路投产（YOLO，无模板备用）

检测一律旧压鞋机 YOLO。`vision.method: yolo`。OpenCV 只用于相机出图和棋盘格内参，不做形状模板匹配。

1. **皮带抓鞋（cam1）**：彩色+深度 → YOLO 鞋 OBB → 左右脚分类 → 楦 OBB → 像素+深度→相机 XYZ → 手眼 4×4 → 机器人毫米 `(x,y,z,yaw)`，鞋头距写入抓取 TCP 的 `+Y`。配置：`shoe_vision_config.json`（`roi_ratio`、内参、`handeye.mat`）。
2. **放料槽有无鞋（cam3）**：YOLO 二分类，0=空槽，1=有鞋。
3. **鞋头对位（cam2）**：toe_align 分类模型。0=到位，1=向前。Station2 用相对 MoveL 推进。
4. **取料槽（cam4）**：有无鞋分类 + 压杆/夹爪 X 距 → 基座 XY 毫米，只叠加到示教取料点。

把旧工程 `models/` 拷到本工程 `models/`（HMI「视觉采图」→「挂接旧模型」，或 `bash tools/yolo_train/link_legacy_models.sh`）。分类可在该页采图训练。左右脚旧模型不能用时：点「左右脚采图/训练」→ 选左脚/右脚 → 采图（自动抠鞋，把鞋头转到朝上）→ 两类都采够再训练。OBB 可继续用旧权重。未装 ultralytics 或缺 `.pt` 时，该路保持 Mock；皮带用「屏蔽取料」。

HMI：**视觉采图**（写 `shoe_vision_config.json`、求解手眼、写入 PickPose、MoveL），**视觉调试**（出图/ROI/棋盘格/点像素），**相机监控**为独立窗口。棋盘格只标内参：内角点 11×8、边长 15mm。ROI 文件：`config/roi/camN.json`。

### 5.0 共同：先出真图

1. USB 插稳；点「枚举设备」抄 serial。  
2. 填 serial（优先）→「写入serial并重开」。空 serial 才用 index；Gemini 彩色不要用 video-index0/1。  
3. **取消该路 Mock**，预览出真图再往下做。  
4. 四路 serial 不要填成同一台。  
5. 拷模型后看「YOLO模型」框和顶部「✓/✗ 皮带-鞋OBB …」。缺哪个补哪个。

### 5.1 cam1 皮带上料

职责：给出上料臂**示教器基座毫米**取料坐标、左右脚、鞋头 TCP 的 Y。

1. 出真图，皮带和整只鞋清楚。  
2. `shoe_vision_config.json`：用 HMI「视觉采图」写 `roi_ratio`、内参、`handeye.mat`（不要手改也能完成）。磁盘默认矩阵是旧机的，本机必须重标。本程序**不会**再开一套 RSDT 相机，画面来自 cam1。  
3. 「测试皮带拍照」应出现楦心 XYZ、yaw、左右脚、鞋头距 mm。这就是自动 `runtime_pick`。  
4. YOLO/模型缺失时保持 cam1 Mock，用「屏蔽取料」。

### 5.2 cam2 鞋头对位

职责：放料时看槽/鞋头，分类后相对推进。现装在上料臂上的一般为 Gemini `CV27561000FH`。

1. `vision.toe_align.model_path` 指向旧 `models/toe_align/*.pt`。  
2. 取消 Mock，「测试鞋头对位」：0=到位，1=继续向前。  
3. 左右槽几何仍用 `press_shoes/config/left_slot.yaml` / `right_slot.yaml`。  
4. 模拟时第一次给偏移、第二次到位，方便单步。

### 5.3 cam3 放料鞋槽

职责：槽里有没有鞋（旧 slot_check）。

1. 出真图，「测试槽有无鞋」或「测试放料槽」。  
2. 取消 Mock 后自动用 YOLO 分类；左右鞋槽仍走流程记忆。测右槽可勾 cam3 模拟 + 监视页 Mock。

### 5.4 cam4 取料鞋槽

职责：有没有鞋；有鞋则测压杆 XY，叠加到 `slot_pick`。

1. `position_config.yaml` 里夹爪预设 X、旋转角、ROI 按这台机改。  
2. 「测试取料槽」看有无鞋；「测试压杆偏移」看 dx/dy mm。  
3. 测不到则 Station5 仍用示教点。

### 5.5 手眼文件

- 皮带主用：`shoe_vision_config.json` 里的 `handeye.mat`（相机→基座 4×4）。  
- 本程序采样：`config/calib/<相机>_handeye_samples.json`（棋盘格内参 / 手眼采样）。  
- 矩阵文件：`config/calib/<相机>_handeye.json`。

## 6. 示教点

在「点位」页或直接改 YAML：

**机器人1：** home, pick_entry, pick_above_offset, place_entry, place_slot, place_above_offset  
**机器人2：** home, slot_pick_entry, slot_pick, slot_pick_above_offset, belt_place_entry, belt_place, belt_place_above_offset  

**MoveJ 路点必须存关节角**：示教器走到目标点 →「读入当前TCP+关节」→「保存」。  
配置里为 `j1..j6`（单位°）。有关节则真 `MoveJ`；只有笛卡尔时回退 `MoveCart`（二次从放料进入→取料进入可能拧腕）。  
`*_above_offset` 是相对偏移，不需要关节。

取料点 XYR 由视觉写入 `runtime_pick`；Z/Rx/Ry 用配置默认值。

## 7. 接真机检查清单

- [ ] 要接的设备各自 `use_mock: false`（未到场的保持 `true`）  
- [ ] 对应机器人 IP 能 ping 通  
- [ ] 皮带光电 DI 号填对  
- [ ] 两夹爪 can_id 不同，协议代码补全（`devices/gripper_can.py`）  
- [ ] 压鞋机 Modbus IP/端口/`addr_*`  
- [ ] 工控机急停 DI  
- [ ] 四相机出图 + YOLO 模型 + cam1 手眼 OK  
- [ ] 单站单步验证无干涉  
- [ ] 自动空跑 → 带鞋试产

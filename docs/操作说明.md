# 莆田鞋厂四槽机器控制程序 — 操作说明

面向现场调试与投产。  
**各 HMI 单页「做什么 / 实现文件 / 引用什么 / 被谁使用」以程序内「使用说明」页为准**（`hmi/help_content.py`），本文是安装、联调与检查清单摘要。

---

## 0. ★ 改机器人地址（最常问）

**文件：** `config/default.yaml`（不要去改 `devices/robot_fr5.py`）

| 设备 | yaml 位置 | 默认值 |
|------|-----------|--------|
| 上料机器人 | `robots.robot1.ip` | `192.168.1.105` |
| 下料机器人 | `robots.robot2.ip` | `192.168.1.115` |
| 压鞋机 | `press.ip` / `press.port` | `192.168.1.50:502` |
| 夹爪 | `grippers.gripper1/2.can_id` | `0x103` / `0x104` |

也可打开 HMI → **通信配置** → 改 IP → **保存配置**（写回同一 yaml）。  

### 分设备 Mock（只有一台真机时）

不要只改 `system.use_mock`。应改各设备自己的开关，例如：

```yaml
robots:
  robot1:
    use_mock: false   # 上料真机
  robot2:
    use_mock: true    # 下料仍模拟
grippers:
  gripper1: { use_mock: true }
  gripper2: { use_mock: true }
press:
  use_mock: true
vision:
  use_mock: true
```

HMI「通信配置」页也有对应勾选。改完**重启程序**。

## 1. 安装与启动

```bash
cd 莆田鞋厂四槽机器控制程序
python3 -m pip install --user --break-system-packages -r requirements.txt
python3 main.py
```

- 默认各设备 `use_mock: true`，**无真机也能打开 HMI**。  
  接真机时只把对应设备的 `use_mock` 改为 `false`，并安装法奥 SDK（`pip install -e ../fairino`）。
- 若窗口闪一下就退出：Wayland 用 `QT_QPA_PLATFORM=wayland python3 main.py`，或 Cursor 调试配置「运行主程序」。  
  X11 用户需：`sudo apt install libxcb-cursor0`

## 2. HMI 分页（摘要）

详细说明（实现路径、引用、被谁调用）→ 打开软件 **「使用说明」** 标签。

| 页 | 用途 |
|----|------|
| 运行监控 | 初始化/启动/暂停/停止/急停、三色灯、记忆、Mock 信号 |
| 产量统计 | 下料记件、CT、UPH |
| 工位调试 | 按工位/Auto 单步跑、调试旁路 |
| 运动参数 | 按程序步调 vel / 平滑 |
| 视觉采图 | 新机：模型/训练/写 json 手眼/测皮带/试抓 |
| 视觉调试 | YOLO 出图/ROI/内参/检测测试 |
| 示教点位 | 上料 R1 / 下料 R2 示教点、过渡点 |
| 屏蔽取料 | cam1 Mock 皮带取料示教 |
| 空跑联调 | 无真机走通工位 1～6 |
| 负载工具 | 两臂负载与 TCP |
| 压机信号 | 左右口、槽号、Modbus |
| 通信配置 | 机器人 IP、压鞋机、夹爪 CAN、光电 DI |
| 报警记录 | 历史与复位 |
| 使用说明 | **完整手册（含算法接口、工位、设备索引）** |

**相机监控**是独立窗口：启动后自动弹出；关掉后点主界面顶部「相机监控窗口」再打开。

### 灯语

- 绿常亮 = 自动运行  
- 黄+绿常亮 = 初始化完成（READY，可启动）  
- 黄常亮 = 停止后 / 未初始化  
- 黄闪 = 初始化中 / 暂停 / 单步中  
- 红常亮 = 报警  
- 红闪 = 急停  

### 记忆

- `Mem1～10`：程序内部 BOOL（`core/gvl.py` 的 Memory_BOOL）。  
- **自动运行中锁定**；暂停/停止/报警/单步/空闲时可勾选修改。

## 3. Mock 下快速走通自动流程（推荐先做）

1. 打开软件，模式选 **自动**。  
2. 点 **初始化**（Mock 会很快完成）→ 状态变 READY（黄+绿）。  
3. 「空跑联调」一键启用；或在运行监控勾光电、Mock 取料槽有料、放料空槽。  
4. 「屏蔽取料」确认左右鞋示教点。  
5. 点 **启动**。观察 Station1 → 2 → 3 → … → 6（先压合再旋转）。  

---

## 4. 单步调试（验证每个动作）

1. 模式切 **单步** → **初始化** → **启动**。  
2. 「工位调试」选 Station / Auto → **武装所选 Auto**（互锁不够可勾 **调试旁路**）。  
3. **执行当前步** / **下一步**：跑到条件满足后停住。  
4. **中止本 Auto** 清空该站步号（记忆需在监控页改）。  

引导失败（cam2）：停在放料点、夹爪仍夹着 → 暂停 → 报警复位 → 启动 → 从引导步继续。

## 5. 视觉摘要

检测用 YOLO（经 `algorithm_module` / `VisionService`）。缺模型则该路 Mock；皮带用「屏蔽取料」。

| 相机 | 作用 | 主要调用 |
|------|------|----------|
| cam1 | 皮带取料位姿 | Station1 ← `photo_belt_pick` ← `algo.detect_belt_pick` |
| cam2 | 鞋头对位 | Station2 ← `toe_place_assist` ← `algo.classify_toe_align` |
| cam3 | 放料槽有无鞋 | Station3 ← `photo_place_slot` |
| cam4 | 取料槽+压杆 | Station4/5 ← `photo_pick_slot` / `measure_rod_offset_mm` |

配置：`shoe_vision_config.json`、`config/roi/`、`config/calib/`、`models/`。  
投产向导：HMI「视觉采图」；出图测试：「视觉调试」；实时看图：「相机监控」。

棋盘格内参默认内角点 11×8、边长 15mm。

## 6. 示教点

**机器人1：** home, pick_entry, pick_above_offset, place_entry, place_slot, place_above_offset  
**机器人2：** home, slot_pick_entry, slot_pick, slot_pick_above_offset, belt_place_entry, belt_place, belt_place_above_offset  

MoveJ 路点请同时存 TCP + `j1..j6`（°）。只有笛卡尔时可能回退 MoveCart。  
`*_above_offset` 为相对偏移。取料 XYR 常由视觉写入 `runtime_pick`。

运动指令：封装为 `move_j` / `move_l` → 法奥 **MoveJ / MoveL**（见「使用说明」设备章）。

## 7. 接真机检查清单

- [ ] 要接的设备各自 `use_mock: false`（未到场的保持 `true`）  
- [ ] 对应机器人 IP 能 ping 通  
- [ ] 皮带光电 DI 号填对  
- [ ] 两夹爪 can_id 不同  
- [ ] 压鞋机 Modbus IP/端口/`addr_*`  
- [ ] 工控机急停 DI  
- [ ] 四相机出图 + YOLO 模型 + cam1 手眼 OK  
- [ ] 单站单步验证无干涉  
- [ ] 自动空跑 → 带鞋试产

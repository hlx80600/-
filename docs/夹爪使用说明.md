# 夹爪使用说明 — 达妙 DM-J4310-2EC（48V）

本机双臂各配一只夹爪，驱动电机为**达妙科技 DM-J4310-2EC（48V 版）**，经 **CAN 总线**由工控机控制。

**全部夹爪代码已合并为单文件：** [`devices/gripper_can.py`](../devices/gripper_can.py)  
（CAN 收发、使能、反馈解析 + 工位/HMI 对外接口，均在此文件；**使用时只 import 本文件的接口**。）

电机控制模式：**位置速度模式**（命令帧 = 目标位置 rad + 运动速度 float，非 MIT 模式）。

---

## 1. 程序接口（怎么用）

### 1.0 最多 99 路电机（HMI 选用）

配置在 `config/default.yaml` → `grippers`：

| 字段 | 含义 |
|------|------|
| `max_motors` | 容量上限 **99**（固定） |
| `motor_count` | **实际启用数量**（1～99），HMI「通信配置」里改 |
| `motors."1"…"N"` | 每路：`interface` / `can_id` / `gripper_type` / 速度 / Mock |
| `load_index` | 上料工位绑定的电机序号 → `ctx.gripper1` |
| `unload_index` | 下料工位绑定的电机序号 → `ctx.gripper2` |

**HMI 操作：** 通信配置 → 设「启用电机数量」→ 表格只出现启用行 → 填 CAN 接口与 can_id → 保存。  
改数量后请**重启程序**。运行时：`ctx.grippers[序号]` 取各路；流程仍用 `ctx.gripper1` / `ctx.gripper2`。

辅助模块：`devices/gripper_bank.py`（规范化 / 别名同步）。

### 1.1 推荐 import

```python
from devices.gripper_can import GripperCAN, create_gripper, create_gripper_from_config
from devices.gripper_bank import normalize_grippers_cfg
```

| 接口 | 用途 |
|------|------|
| `create_gripper_from_config(yaml片段, name=...)` | 从单路电机字典创建 |
| `create_gripper(...)` | 脚本/测试直接创建 |
| `ctx.gripper1` / `ctx.gripper2` | 上料/下料绑定（Station 使用） |
| `ctx.grippers[i]` | 第 i 路启用电机（1-based） |

### 1.2 工位扫描（非阻塞，Station2/5）

```python
ctx.gripper1.open()          # 发张开
if ctx.gripper1.poll_done(): # 反馈到位（或 Mock 延时到）
    ...                      # 跳下一步
```

```python

    ...
```

### 1.3 HMI / 脚本（阻塞到反馈）

```python

```

## 3. 硬件与接线

| 项目 | 说明 |
|------|------|
| 型号 | DM-J4310-2EC（48V） |
| CAN | 标准帧，**1 Mbps** |
| 电源 | XT30(2+2)-F；**48V 电源**（48V 版工作约 24～58V） |
| 电机模式 | 达妙调试助手中应为 **位置速度模式** |
| 使能 | `connect()` 时自动发 enable |

CAN 布线：can0 上料、can1 下料；总线两端 120Ω（按模块说明）；48V 近端加保护。

**上电顺序：** 工控机 → 配置 can0/can1 → 夹爪 48V → 启动程序。

---

## 4. Linux 配置 CAN

```bash
sudo ip link set can0 down 2>/dev/null
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up

sudo ip link set can1 down 2>/dev/null
sudo ip link set can1 type can bitrate 1000000
sudo ip link set can1 up
```

## 5. yaml 参数（`config/default.yaml`）

```yaml
grippers:
  max_motors: 99
  motor_count: 2
  load_index: 1
  unload_index: 2
  motors:
    '1':
      label: 上料
      interface: can0
      can_id: 259          # 0x103
      gripper_type: 2
      open_speed: 50.0
      close_speed: 50.0
      use_mock: true
    '2':
      label: 下料
      interface: can1
      can_id: 257
      gripper_type: 2
      open_speed: 100.0
      close_speed: 50.0
      use_mock: true
```

| 参数 | 含义 |
|------|------|
| `motor_count` | 启用路数；HMI 表格行数与此一致 |
| `gripper_type` | 开合命令帧预设；本机型 **= 2** |
| `open_speed` / `close_speed` | 位置速度模式下的速度字 |
| `use_mock` | `false` 接真机 |

HMI：**通信配置** 改数量与地址；**运行监控** 可改上料/下料速度并保存。

## 6. HMI 操作

- **通信配置** →「夹爪电机」：设启用数量（1～99）→ 表格填每路 CAN 接口 / can_id → 设上料/下料绑定序号 → 保存  
- **夹爪调试**（独立页）：选电机 → 张开/夹紧 → 速度保存 → 重连 → 掉落检测 → **报警复位（含夹爪）**  
- **运行监控** → 上料/下料快捷开合；「报警复位」同样清 GRIP_*  

### 夹爪报警 GRIP_*

| 代码 | 含义 |
|------|------|
| `GRIP_LINK` | CAN 连接 / 使能失败 |
| `GRIP_OPEN` | 张开反馈失败 |
| `GRIP_CLOSE` | 夹紧反馈失败 |
| `GRIP_DRV` | 驱动/掉落等 |

开合失败或连不上会写进报警队列并停机（进 ALARM）。  
**报警复位**会：`alarms.reset()` + 清各爪 `last_error` + 尝试重连真机夹爪。

### 自动流程何时开合

| 工位 | 夹爪 | 动作 |
|------|------|------|
| Station2 取料 | gripper1 | 张爪 → 夹紧 |
| Station2 放料 | gripper1 | 对位后张爪 |
| Station5 取槽 | gripper2 | 张爪 → 夹紧 |
| Station5 放皮带 | gripper2 | 张爪 |

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| 连不上 | `ip link` 查 can0/can1 是否 UP；48V 与 CAN 线 |
| 使能失败 | 核对 can_id；电机是否为位置速度模式 |
| 自动卡在某步 | 降 `close_speed`；查机械是否夹到位 |
| Mock 正常真机不动 | `use_mock: false` 并重启 |

---

## A. 新机 / 换型 — 总顺序（必须按序）

```text
① 通信配置（IP/CAN/Mock）→ 保存 → 重启程序
② 负载工具（手爪 TCP / 抓鞋负载）→ 保存并下发
③ 示教点位（进入点、槽点、偏移）→ 保存
④ 运动参数（各步速度/是否平滑）→ 保存
⑤ 压机信号（槽号顺序、地址）→ 保存
⑥ 视觉（总页子页签：ROI→内参→手眼→检测测试；采图训练挂/训模型）
   拍过图后到「报警记录 → 运行快照」核对原图/叠图（文件名含相机与时间）
⑦ 屏蔽取料（仅 cam1 模拟时）
⑧ 夹爪调试（单机开合确认）
⑨ 空跑联调 / 工位调试单步
⑩ 运行监控：自动 → 初始化 → 启动
```

**原则：** 先通设备与示教，再做视觉标定；视觉未好之前用 Mock + 屏蔽取料空跑。

## B. 各界面怎么做（按导航顺序）

### 1. 运行监控

| 做什么 | 怎么做 |
|--------|--------|
| 每日生产 | 模式选「自动」→ **初始化** → 灯黄+绿（READY）→ **启动** |
| 暂停改记忆 | **暂停** → 勾选/取消 Mem → 再启动 |
| 急停后 | 报警复位 → 再初始化 → 启动 |
| 全局速度 | 拖「全局速度」滑条（与「运动参数」里各步 vel% 相乘） |
| 空跑 | 勾相关模拟或点「启动空跑」；详见「空跑联调」 |
| 打开相机窗 | 顶部「相机监控窗口」（启动时不自动弹出） |

**不要：** 自动运行中改记忆（界面会锁）。

---

### 2. 产量统计

看件数 / CT / UPH。可「模拟记一件」测看板（不驱动机械）。

---

### 3. 工位调试

| 步骤 | 操作 |
|------|------|
| 1 | 运行监控：模式 **单步** → 初始化 → 启动 |
| 2 | 本页选 Station（1～6）与 Auto |
| 3 | **武装所选 Auto**（互锁不够可勾「调试旁路」，需 yaml 允许） |
| 4 | **执行当前步** / **下一步** |
| 5 | **中止本 Auto** 清步号；记忆仍在运行监控改 |

用于：单独验证取料、放料、压合等，不必整线自动。

---

### 4. 运动参数

按程序步改 `vel` / `acc` / `blend`（如 `s2a10_90`）。  
**退回进入点、下压取料点等关键步建议 blend=关（到位）**，否则会未到点就写记忆。保存写回 yaml。

### 5. 视觉（总页）

左侧导航仅 **「视觉」** 一项。上方常驻相机预览；下方子页签：

| 子页签 | 内容 |
|--------|------|
| 相机与ROI | Mock、serial 绑定、ROI 绿框 |
| 棋盘格内参 | 检测/采集/计算内参 |
| 手眼标定 | 点像素采样、求解、写入 json |
| 检测测试 | YOLO 各路测试、PickPose / MoveL |
| 采图训练 | 原「视觉采图」向导（挂模型/训/写 json/试抓），首次点开再加载 |

**运行快照**不在本总页：左侧 **报警记录** → 第四个页签 **运行快照**（完整说明见 **§14.4**）。

#### 5.1 采图训练（投产向导 ①～⑤）

| 编号 | 内容 | 操作要点 |
|------|------|----------|
| ① | 环境与模型 | 「检查 YOLO」→「挂接旧模型」或「选用 .pt 写入配置」 |
| ② | 采图/训练 | 选槽位（皮带 OBB / 左右脚 / 鞋头 / 槽有无鞋）→ 采图 → 训练（CPU/GPU） |
| ③ | 内参与手眼写入 | **先在「棋盘格/手眼」页签采好**，再回本页签写入 shoe_vision_config.json |
| ④ | 测皮带取料 | 取消 cam1 Mock → 测拍照 → 写 PickPose → MoveL 试上方 |
| ⑤ | 单步验证 | 跳转「工位调试」跑 Station1/2 |

左右脚可在本页签重训；**点像素在上方预览区点，再切手眼标定页签记录**。

「检测测试」测皮带 / 放料槽 / 取料槽会写入运行快照，查图到 **§14.4**。视觉页「截图保存」是标定图（`config/vision_snaps/`），不是运行快照。

### 6. 视觉标定顺序（ROI / 内参 / 手眼）— ★ 详细

对 **每一路需要真机视觉的相机**（通常至少 cam1）按下面做。

#### 6.1 准备工作

1. 「通信配置」里该相机 `use_mock=false`，填好 **serial**，保存并重启。  
2. 打开「视觉」，下拉选中相机（cam1～cam4）。  
3. 「相机与ROI」→「枚举设备」→ 核对列表 → 「绑定 serial 并重开」。  
4. 预览有图；可开「相机监控窗口」对照。

#### 6.2 ROI 绿框（先做）

1. 拖绿框或「中间半张图」/「铺满整张图」。  
2. **写入配置（保存 ROI）** → 文件 `config/roi/<相机>.json`。  
3. cam1 投产时再点「ROI 写入皮带 json」（手眼页签，进 shoe_vision_config）。

#### 6.3 棋盘格内参

默认内角点 **11×8**、格边 **15mm**（可在 yaml `vision.chessboard` 改，须与实物一致）。

1. 棋盘格放在该相机视野内、铺满尽量多角度。  
2. 点 **检测棋盘格** → 画面有角点才算有效。  
3. 点 **采集有效帧**（多采 10～20 帧，变换角度/距离）。  
4. **计算并保存内参** → `config/calib/<相机>_intrinsics.json`。  
5. cam1：再点 **内参写入皮带 json**。

#### 6.4 手眼标定（cam1 皮带必做；其它相机按需）

目标：像素点 ↔ 上料臂基座/TCP，使「测试皮带拍照」出的 XY 能用于取料。

**推荐采点方式（eye-to-hand 常见做法）：**

1. 上料臂装好标定针/尖点（或夹爪尖），示教器手动。  
2. 在预览画面 **点击** 针尖对应像素（出现待写入像素）。  
3. 针尖停稳后，点 **记录手眼采样点**（自动读当前 TCP）。  
4. **换位置** 重复：建议 **≥ 8～12 点**，铺满皮带工作区，高低略变。  
5. **保存手眼采样**（可随时存盘）。  
6. **计算手眼 4×4 写入 json** → `config/calib/<相机>_handeye.json`；cam1 同时写入 `shoe_vision_config.json`。  
7. 用 **测试皮带拍照** 看 X/Y/鞋长/鞋头偏移是否合理 → **视觉结果写入 PickPose** → **MoveL 到取料上方** 目视是否对准。

**注意：**

- 必须先有内参，再求解手眼。  
- 采样时 TCP 与像素必须是同一时刻姿态。  
- 算错可「清除手眼采样 / 清除手眼矩阵」后重采。  
- 手眼改完一般 **重启程序** 再跑自动最稳。

#### 6.5 各路「测试」按钮对照

| 按钮 | 相机 | 说明 |
|------|------|------|
| 测试皮带拍照 | cam1 | Station1 同源；看楦心、鞋长、鞋头偏移 |
| 测试鞋头对位 | cam2 | 到位 / 需向前 |
| 测试放料槽 / 槽有无鞋 | cam3 | 空/有料 |
| 测试取料槽 / 压杆偏移 | cam4 | 有料 + 压杆 XY |
| 测试贴边引导 | cam2 相关 | 引导偏移 |

某路缺模型或 Mock=开 → 走模拟结果；皮带 Mock 用「屏蔽取料」示教点。

### 7. 示教点位

| 臂 | 必教点 |
|----|--------|
| 上料 R1 | `home`，`pick_entry`，`pick_above_offset`，`place_entry`，`place_slot`，`place_above_offset` |
| 下料 R2 | `home`，`slot_pick_entry`，`slot_pick`，`slot_pick_above_offset`，`belt_place_entry`，`belt_place`，`belt_place_above_offset` |

操作：选点 → 点 **打开示教器**（或顶栏「示教器」）挪到位 → **读入当前 TCP+关节** → **保存当前点**。  
**按住 MoveJ/MoveL 到此点** 才运动，松开立刻停；到位会弹窗。点按不会动。  
试跑速度用本页 **速度条**（默认 8%，上限 25%），不改运行监控全局速度、也不影响自动。  
取料 XY 常由视觉写入；`*_above_offset` 为相对偏移。改完可路径试跑。

#### 7.1 示教器（独立窗口）

主界面右上 **示教器**，或本页 **打开示教器**：弹出独立窗口，不必离开当前页、也不必切法奥示教器。  
选上料/下料臂，坐标系选基座 XYZ / 工具 XYZ / 关节。默认 **按住连续**（按住才动，松开立刻停）；**点按一步** 按设定 mm/° 走一次。  
默认窗口置顶，可一边看点位一边点动。速度上限 25%，建议先 **8%～15%**。  
自动连续运行、急停、报警时锁定。关示教器窗口即停点动。夹爪开合仍用「夹爪调试」。

### 8. 屏蔽取料

**仅当 cam1 为 Mock**（无相机/未标定时）必做：录入左右鞋示教 XY/角度/鞋头偏移，保存。  
真机 YOLO+手眼成功后可不用本页。

---

### 9. 空跑联调

无真皮带/压机时：启用空跑 → 自动模拟光电、压合/旋转延时、槽有无料时序。  
配合「屏蔽取料」+ Mock 相机，可在运行监控走通 Station1～6。

---

### 10. 负载工具

分别设 **未抓鞋（负载1 + 工具TCP1）** / **抓鞋（负载2 + 工具TCP2）** 的质量、质心、TCP。  
绿色框和「● 当前使用」表示本臂**正在用哪一套**；上方状态栏同时写清当前负载编号和运动工具/TCP。  
「切到 1 / 切到 2」会**同时**切换负载和工具 TCP。自动取料夹紧后可能出现负载2、仍用工具1，状态栏会黄底提示。  
保存并可勾选下发到控制器。抓取后鞋头 TCP 由流程按视觉偏移改写工具2列表。

---

### 11. 压机信号

设开口左右、槽号顺序（12341/43214）、各槽线圈地址、手动压杆/压合。  
与 Station6、运行监控槽号同源。

---

### 12. 夹爪调试

选电机 → 使能 → 开/合 → 看反馈。报警见「报警记录」与 [夹爪使用说明.md](夹爪使用说明.md)。

### 13. 通信配置

改机器人 IP、压机、夹爪 CAN、相机 serial、各设备 Mock。  
**保存后重启 `python3 main.py`。**

### 14. 报警记录

左侧导航 **报警记录**。四个页签：**本次运行** / **落盘错误** / **黑匣子** / **运行快照**。  
文件都在项目 `logs/`（不进 git）。「打开日志目录」打开整个 `logs/`；运行快照页另有「打开视觉log文件夹」，只打开 `logs/vision_snaps/`。

| 页签 | 看什么 | 退出程序后再开 |
|------|--------|----------------|
| 本次运行 | 当前这次启动后的报警 | 否（请看落盘错误 / 黑匣子） |
| 落盘错误 | WARNING / ERROR / 报警写入磁盘 | 是 |
| 黑匣子 | 故障前后运行轨迹；崩溃另有 `logs/dumps/` | 是 |
| 运行快照 | 生产拍照原图/叠图 + 运送回写 | 是 |

#### 14.1 本次运行

当前启动后的报警，**分页**（每页 20 条，新的在前）。可选中后复制、报警复位、打开可复制窗口。  
刷新时若正在选中某条，不会清掉选区。退出程序后本页清空，历史请切「落盘错误」或「黑匣子」。

#### 14.2 落盘错误

WARNING / ERROR / 报警写入 `logs/errors_YYYY-MM-DD.jsonl`（另有 `app_YYYY-MM-DD.log`、`error_YYYY-MM-DD.log`，文件名带当天日期）。  
同样分页；可刷新、复制本页。关机后再开程序仍能查。

#### 14.3 黑匣子

故障前后一段时间的运行轨迹（环形记录 `logs/blackbox_YYYY-MM-DD.jsonl`）。崩溃或严重错误时还会在 `logs/dumps/` 再打一份带时间戳的内存快照。  
这是**程序轨迹**，不是相机照片。相机照片在下一页签「运行快照」。

#### 14.4 运行快照（生产拍照 + 运送结果）

用来回答两件事：**当时相机看见什么**，以及 **后来运到哪里、运得对不对**。两者写在同一条记录上，可在触摸屏上翻，不必上工控机找文件夹。

##### 14.4.1 什么时候会存一张

| 时机 | 相机 | 说明 |
|------|------|------|
| Station1 皮带拍照 | cam1 | 自动每次拍照都存（成功/失败都存）。确认本拍取料位后，把编号挂到这只鞋上，后面运送结果写回这一条 |
| Station3 放料槽拍照 | cam3 | 空槽 / 有料、左右槽判定 |
| Station4 取料槽拍照 | cam4 | 有无料、压杆偏移 |
| 视觉「检测测试」手动测皮带 / 放料槽 / 取料槽 | 对应路 | 与生产同一套接口，方便对模型 |
| 「视觉结果写入 PickPose」 | cam1 | 也会带上本次编号；若接着跑自动放料，仍可回写运送结果 |

**不会存**（避免刷盘、也对不上「哪一只鞋」）：

- 顶部「相机监控」窗口的实时推演、监视定时刷新
- cam2 鞋头对位、贴边引导（运动中反复拍）
- 视觉页上方「截图保存」→ 标定截图，目录是 `config/vision_snaps/`，**不是**运行快照

##### 14.4.2 文件在哪、一张图怎么命名

根目录：`logs/vision_snaps/`。按日期：

```text
logs/vision_snaps/YYYY-MM-DD/<快照id>/
  cam1_20260828_140455_635_belt_pick_raw.jpg   原图
  cam1_20260828_140455_635_belt_pick_vis.jpg   叠了检测框/文字的图
  meta.json                                    检测结果 + transport（运送回写）
logs/vision_snaps/index_YYYY-MM-DD.jsonl   当日总索引
```

**JPEG 文件名** = `相机_日期_时刻毫秒_类型_raw.jpg` / `_vis.jpg`。拷文件时不必打开文件夹也能分辨是哪路相机、哪一刻。例如：

| 文件名片段 | 含义 |
|------------|------|
| `cam1` / `cam3` / `cam4` | 哪路相机拍的 |
| `20260828_140455_635` | 拍照时间（含毫秒） |
| `belt_pick` / `place_slot` / `pick_slot` | 类型（皮带取料 / 放料槽 / 取料槽） |
| `_raw` / `_vis` | 原图 / 叠图 |

快照文件夹 id 例：`20260828_111343_635_cam1_belt_pick`（时间 + 相机 + 类型）。  
旧记录若仍是 `raw.jpg` / `vis.jpg`，本页仍能打开。

##### 14.4.3 运送完成后再写回什么

写在该条 `meta.json` 的 `transport` 里。详情「运送结果」、列表右侧「已放槽#2 / 未运送 / 可放料 / 已下料」都读这里。

| 字段 | 何时写 | 写在哪条快照上 | 内容 |
|------|--------|----------------|------|
| `place` 放入鞋槽 | Station2 放料完成、回到 place_entry | cam1 皮带那一拍 | 成功与否、放料槽号、左右脚 |
| `slot_check` 槽判定 | Station3 判定结束 | cam3 本拍，并同步到正在运送的 cam1 那一拍 | 可放料 / 左右不配只转不压 / 槽内有料禁止放 |
| `unload` 下料到皮带 | Station5 放到皮带并记产量 | cam4 取料槽那一拍 | 成功与否、取料槽号 |

详情写「尚未回写」：还在途中，或只点了检测测试没跑自动。点 **刷新** 再看。

##### 14.4.4 在本页怎么查

1. 左侧导航 **报警记录** → 页签 **运行快照**（在「黑匣子」右边）。
2. **打开视觉log文件夹**：系统文件管理器打开 `logs/vision_snaps/`。
3. 左侧列表 **新的在前**；可按相机、类型筛选；每页 20 条。
4. 点一条：右侧 **原图、叠图**；下方检测数据（坐标、左右脚、鞋长、有无料等）和运送回写。
5. 刚放完料或刚下料：点 **刷新**，同一条上会出现「已放槽#n」或「已下料」。
6. **打开本条目录**：打开这一拍的文件夹，可拷带相机与时间的 jpg 和 `meta.json`。
7. **复制详情**：把当前说明拷到剪贴板。

不要和下面几个按钮搞混：

| 按钮 | 目录 | 用途 |
|------|------|------|
| 运行快照 → 打开视觉log文件夹 | `logs/vision_snaps/` | 生产运行记录，带运送结果 |
| 视觉页 → 截图目录 | `config/vision_snaps/` | 「截图保存」的标定图，无运送结果 |
| 视觉页 → 标定目录 / YOLO模型目录 | `config/calib/`、`models/` | 内参手眼、权重 |
| 报警记录 → 打开日志目录 | 整个 `logs/` | `app_日期.log`、黑匣子；视觉快照是其中的 `vision_snaps/` 子目录 |

##### 14.4.5 开关与保留

`config/default.yaml`：

- `vision.save_runtime_snaps`：默认 `true`；改 `false` 则完全不存
- `vision.snap_keep_days`：默认 `7`，过期日期目录会自动删

改完 **重启程序** 生效。

##### 14.4.6 排故怎么用

- 取偏、抓空：筛 cam1 / 皮带取料，对照叠图和 X/Y/Rz、左右脚、鞋长。
- 放错槽、只转不压：看 cam1 的 slot_check / place，以及 cam3 判定原文。
- 下料取空：筛 cam4，看有无料、压杆偏移，以及 unload 槽号。
- 列表仍「未运送」但流程已走完：先刷新；仍没有则看本页「本次运行 / 黑匣子」是否中途停过。
- 图显示「暂无」：JPEG 在后台写，等一两秒再刷新。
